## 2. 비즈니스 모델

### 추천 전략: 단계적 전환

| 단계 | 모델 | 목적 |
|------|------|------|
| 초기 | **오픈소스 코어 (Open Core)** | 인지도 확보, 커뮤니티 빌딩 |
| 중기 | **API-as-a-Service (종량제)** | 첫 수익화, 스타트업 고객 |
| 후기 | **SaaS 구독형 (B2B)** | 안정적 MRR, 엔터프라이즈 |

### 가격 구조 (안)

| 티어 | 가격 | 포함 내용 |
|------|------|-----------|
| Free | 무료 | 월 10,000건, 기본 대시보드, 커뮤니티 지원 |
| Pro | 월 29,000원~ | 월 100,000건, 커스텀 알림, 이메일 지원 |
| Enterprise | 협의 | 무제한, 전용 인프라, SLA, 컴플라이언스 리포트 |

## 3. 타겟 페르소나

### 1차: 초기 핀테크 스타트업 CTO
- **Pain**: 규제 준수를 위한 거래 모니터링이 필수인데 자체 구축 여력 없음
- **Value**: API 연동 30분이면 모니터링 체계 완성, 종량제로 비용 부담 최소화

### 2차: 전통 금융사 디지털 혁신팀
- **Pain**: 레거시 FDS가 배치 기반이라 실시간 탐지 불가, 대시보드 부재
- **Value**: 기존 시스템 병행 운영 + 실시간 레이어 추가, Grafana로 경영진 보고 자동화

### 3차: 1인 개발자 / 사이드 프로젝트 빌더
- **Pain**: 금융 모니터링 학습 자료 부족, 풀스택 세팅 부담
- **Value**: 오픈소스 코드 자체가 학습 자료, Docker Compose 원클릭 실행

## 4. 경쟁 우위

| 차별점 | 설명 |
|--------|------|
| **한국 금융 규제 네이티브** | 전자금융거래법, 신용정보법 기본 탑재. 글로벌 솔루션의 한국 시장 약점 |
| **풀스택 단일 플랫폼** | CRUD + 스트리밍 + 모니터링 + 검색 + 이상탐지 통합 |
| **개발자 친화 오픈소스** | 국내 금융 모니터링 오픈소스 전무. 코드 공개로 블랙박스 불신 해소 |
| **스타트업 친화 비용** | 기존 FDS 수천만원 vs Finora 무료 시작 |

## 7. 0원 인프라 전략

> 현재 단계에서는 비용 0원으로 운영한다. 유료 전환은 PMF 달성 후.

| 항목 | 무료 옵션 | 제한 | 유료 전환 시점 |
|------|-----------|------|----------------|
| 코드 호스팅 | GitHub | 무제한 | 전환 불필요 |
| 백엔드 배포 | Render Free | 750시간/월 | 트래픽 초과 시 |
| DB | Supabase Free (PostgreSQL) | 500MB, 2 프로젝트 | 데이터 500MB 초과 시 |
| 프론트 배포 | Vercel Free | 100GB 대역폭/월 | 커스텀 도메인 필요 시 |
| 모니터링 | Grafana Cloud Free | 메트릭 10k/월 | Enterprise 고객 확보 시 |
| 검색 | 로컬 ES (Docker) → Bonsai.io Free | 125MB | 프로덕션 이관 시 |
| 메시징 | 로컬 Kafka (Docker) → CloudKarafka Free | 5 토픽, 10MB | 프로덕션 이관 시 |
| CI/CD | GitHub Actions | 2,000분/월 | 전환 불필요 |
| 도메인 | 서브도메인 활용 (*.vercel.app) | 브랜딩 제한 | Phase 1 이후 |

### 로컬 개발 vs 배포 분리
- **로컬**: Docker Compose로 전체 스택 (PostgreSQL + Kafka + ES + Grafana)
- **배포**: 무료 티어 조합 (Render + Supabase + Vercel)
- **전환**: 로컬에서 검증 → 무료 클라우드로 이관 → 유료 필요 시 점진적 전환
