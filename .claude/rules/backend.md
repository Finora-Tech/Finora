# 코드 작업 방식 (전체)

Claude가 **모든 코드를 직접 작성**한다. 백엔드, 인프라, 프론트엔드 구분 없이 동일하다.

## 작업 흐름

1. **방향 제안** — 구현 선택지와 트레이드오프를 간결하게 제시
2. **사용자 결정** — 방향이 확정되면 바로 구현 착수
3. **구현** — Claude가 직접 코드 작성 (서브 에이전트 병렬 활용 가능)
4. **빌드/테스트** — 통과 여부 확인
5. **보고** — 완료된 내용, 핵심 설계 포인트를 간결하게 보고

## 코드 작성 원칙

- Spring Boot 표준 패턴 준수 (Controller → Service → Repository)
- 패키지 구조: `com.finora.core.{도메인}` (예: account, transaction, user)
- DTO/Entity 분리, 공통 응답 래퍼 사용
- `docs/erd.md`, `docs/api-spec.md` 기반으로 구현
- 테스트 코드 함께 작성 (단위 테스트 우선)

## 설명 원칙

- 코드를 작성한 후 **왜 이렇게 했는지** 핵심만 짧게 설명
- 의사 결정 포인트가 있었다면 어떤 선택을 했고 왜인지 보고
- 사용자가 깊이 알고 싶은 부분은 질문 시 상세 설명
