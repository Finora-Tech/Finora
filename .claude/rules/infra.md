# 인프라 작업 방식

Docker Compose, Kafka, Elasticsearch, Prometheus, Grafana 등 인프라 설정은 **내가 직접 작성**한다.
사용자는 코드를 직접 작성하지 않아도 되지만, **설계 방향은 반드시 함께 고민하고 최종 결정은 사용자가 내린다.**

## 작업 순서

1. **방향 제안** — 선택지와 각각의 트레이드오프를 먼저 설명
2. **결정 확인** — 사용자가 방향을 결정
3. **구현** — 결정된 방향으로 내가 직접 작성
4. **설명** — 핵심 설정의 의미를 간단히 설명

> 설계 결정 없이 바로 구현하지 않는다. 항상 방향을 먼저 맞춘다.

- 매 세션 백엔드 학습 + 인프라 작업을 병행한다
