# 인프라 작업 방식

Docker Compose, Kafka, Elasticsearch, Prometheus, Grafana 등 인프라 설정은 **Claude가 직접 작성**한다.

## 작업 순서

1. **방향 제안** — 선택지와 트레이드오프를 간결하게 설명
2. **결정 확인** — 사용자가 방향을 결정
3. **구현** — 결정된 방향으로 직접 작성
4. **실행 확인** — docker compose up 등 실행 결과 확인
5. **보고** — 핵심 설정의 의미를 간단히 설명

> 설계 결정 없이 바로 구현하지 않는다. 항상 방향을 먼저 맞춘다.
